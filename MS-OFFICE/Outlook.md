# Outlook Basics

## What is Microsoft Outlook?

**Microsoft Outlook** is an email and personal information management application.

It is commonly used for:

* Email
* Calendar
* Meetings
* Contacts
* Tasks
* Reminders
* Scheduling
* Professional communication

In a workplace such as Accenture, Outlook is especially useful for professional email communication and scheduling meetings.

---

# Email Basics

An email generally contains:

```text
To
Cc
Bcc
Subject
Message Body
Attachments
Signature
```

Example:

```text
To: manager@example.com
Cc: team@example.com
Bcc: audit@example.com

Subject: Project Status Update

Hello,

The project is progressing as planned.

Regards,
Rahul
```

---

# Important Email Fields

## To

Contains the **primary recipient(s)**.

Use it for people who are directly expected to receive or act on the email.

Example:

```text
To: manager@example.com
```

---

## CC

CC means:

> **Carbon Copy**

Used when someone should receive a copy of the email but is not necessarily the primary person responsible for the action.

Example:

```text
To: Manager
CC: Team Lead
```

The Team Lead can see that they were copied on the message.

---

## BCC

BCC means:

> **Blind Carbon Copy**

BCC recipients receive the email, but their email addresses are hidden from other recipients.

Example:

```text
To: person1@example.com
BCC: person2@example.com
```

Person 1 cannot normally see that Person 2 received the email through BCC.

### ⭐ Remember

```text
To  → Primary recipient
CC  → Visible copy
BCC → Hidden copy
```

---

# Subject

The subject briefly describes the purpose of the email.

Good example:

```text
Subject: Project Status Update – August 26
```

Poor example:

```text
Subject: Hi
```

For professional communication, use a clear and specific subject.

---

# Email Body

The body contains the main message.

A professional email commonly has:

```text
Greeting
↓
Purpose
↓
Details
↓
Required action
↓
Closing
```

# Reply, Reply All, and Forward

## Reply

Replies to the sender of the email.

Example:

```text
Original:
Manager → You

Reply:
You → Manager
```

Shortcut in classic Outlook:

```text
Ctrl + R
```

---

## Reply All

Replies to the sender and other relevant recipients included in the original message.

Shortcut in classic Outlook:

```text
Ctrl + Shift + R
```

### Example

Original:

```text
To: Manager
CC: Team Lead
```

Reply All sends the response to:

```text
Manager
Team Lead
```

---

## Forward

Sends the received email to another person.

Example:

```text
Manager → You
             ↓
           Forward
             ↓
        Another person
```

### Shortcut

In classic Outlook:

```text
Ctrl + F
```

### Easy memory

```text
Reply      → Respond to sender
Reply All  → Respond to relevant recipients
Forward    → Send message to someone else
```

# CC vs BCC

This is a very common conceptual question.

| CC                                    | BCC                                                 |
| ------------------------------------- | --------------------------------------------------- |
| Carbon Copy                           | Blind Carbon Copy                                   |
| Recipients are visible                | BCC recipients are hidden                           |
| Used for visible copies               | Used when recipient privacy is needed               |
| Other recipients can see CC addresses | Other recipients generally cannot see BCC addresses |

### Example

```text
To: Manager
CC: Team Lead
BCC: External recipient
```

The external recipient is hidden from the other recipients.

# Attachments

An **attachment** is a file sent along with an email.

Examples:

```text
report.pdf
resume.docx
data.xlsx
presentation.pptx
```

### Common actions

You can:

* Attach a file
* Download an attachment
* Open an attachment
* Save an attachment
* Remove an attachment before sending

### Important

Always verify:

* Correct file
* Correct version
* Correct recipient
* Appropriate permissions/sensitivity

before sending.

# Email Folders

Common Outlook folders include:

## Inbox

Contains received emails.

```text
Inbox → Received messages
```

---

## Sent Items

Contains emails you have sent.

```text
Sent Items → Sent messages
```

---

## Drafts

Contains messages that have been started but not sent.

```text
Drafts → Unfinished messages
```

---

Contains deleted messages until they are permanently removed or automatically purged.


```text
Junk Email → Suspected unwanted messages
```

# Search and Email Organization

Outlook provides search functionality to find emails, contacts, calendar items, and other information.

You can search based on things such as:

* Sender
* Subject
* Date
* Keywords
* Attachments
* Recipient

Example search idea:

```text
from:manager@example.com
```

or:

```text

```

Exact search syntax can vary across Outlook versions.

# Appointment vs Meeting

This distinction can appear in assessments.

## Appointment

An appointment is an event scheduled on your calendar.

Example:

```text
2:00 PM – 3:00 PM
Work on project documentation
```

It does not necessarily involve inviting other people.

---

## Meeting

A meeting involves participants/invitees.

Example:

```text
2:00 PM – 3:00 PM
Project Discussion

Attendees:
Manager
Developer
Tester
```

### Easy memory

```text
Appointment → Your calendar
Meeting     → Participants
```

---

# Meeting Invitations

When someone sends you a meeting invitation, Outlook can provide responses such as:

```text
Accept
Tentative
Decline
```

You can also propose a different time in supported Outlook versions.

---

## Accept

Confirms that you plan to attend.

---

## Tentative

Indicates that you may attend, but you are not fully committed.

---

## Decline

Indicates that you will not attend.

---

# Meeting Organizer

The organizer can typically:

* Add attendees
* Set date/time
* Add meeting details
* Change meeting information
* Cancel the meeting

# Flags

A **flag** can be used to mark an email for follow-up.

Example:

```text
Email:
Client requested updated report.

Flag:
Follow up tomorrow.
```

### Important concept

> **Flag = reminder/follow-up indicator**

---

# Categories

Categories help organize Outlook items using labels/colors.

Example:

```text
Red    → Urgent
Blue   → Project
Green  → Personal
Yellow → Follow-up
```

Categories can be applied to items such as emails and calendar entries.

---

# Flags vs Categories

| Flag                                  | Category                   |
| ------------------------------------- | -------------------------- |
| Indicates follow-up/action            | Organizes/classifies items |
| Often associated with a task/reminder | Used as a label            |
| Example: Follow up tomorrow           | Example: Project A         |

### Easy memory

```text
Flag     → Follow up
Category → Organize
```

---

# Rules

**Rules** automate actions on incoming or outgoing messages.

Example:

```text
IF
sender = manager@example.com

THEN
move message to "Manager" folder
```

Another example:

```text
IF
subject contains "Invoice"

THEN
move to "Finance" folder
```

Rules can help automatically:

* Move messages
* Categorize messages
* Flag messages
* Forward messages in supported scenarios
* Apply other actions

### Easy memory

> **Rules = automatic email actions**

---

# Automatic Replies

Automatic Replies are useful when you are unavailable.

Common example:

```text

```

> **Out of Office / Automatic Reply**

# Junk Email

Junk Email is used for unwanted or suspicious messages.

Common examples:

* Spam
* Unwanted marketing
* Suspicious messages

Be careful with emails containing:

* Unexpected attachments
* Suspicious links
* Urgent requests for passwords
* Requests for financial information

---

# Phishing

**Phishing** is an attempt to trick users into revealing sensitive information or performing an unsafe action.

Examples:

```text
"Your account will be closed today!"
"Click here immediately!"
"Send us your password!"
```

### Warning signs

* Suspicious sender
* Unexpected attachment
* Suspicious link
* Urgent language
* Request for credentials
* Unusual payment request

### Important

Never provide passwords or sensitive credentials simply because an email asks for them.

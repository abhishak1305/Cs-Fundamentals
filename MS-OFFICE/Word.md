# Word Basics

## What is Microsoft Word?

**Microsoft Word** is a word-processing application used to create, edit, format, and print documents.

Common uses include:

* Letters
* Reports
* Resumes
* Assignments
* Documentation
* Business documents
* Meeting notes
* Forms

# Text Alignment

There are four main paragraph alignments.

## Left Alignment

```text
Ctrl + L
```

Text is aligned with the left margin.

---

## Center Alignment

```text
Ctrl + E
```

Text is centered between the margins.

---

## Right Alignment

```text
Ctrl + R
```

Text is aligned with the right margin.

---

## Justify

```text
Ctrl + J
```

Text is aligned with both left and right margins by adjusting spacing.

### Easy memory trick

```text
L → Left
E → cEnter
R → Right
J → Justify
```

# Styles

**Styles** are predefined formatting combinations.

Examples:

```text
Normal
Title
Subtitle
Heading 1
Heading 2
Heading 3
```

### Why use styles?

Styles help:

* Maintain consistent formatting.
* Create structured documents.
* Quickly format headings.
* Generate a Table of Contents.

---

# Heading Styles

Example document structure:

```text
Heading 1
  Introduction

Heading 2
  Background

Heading 2
  Objectives

Heading 1
  Implementation
```

Using heading styles makes a document easier to navigate and helps Word generate a Table of Contents.

---

# Table of Contents

Word can automatically generate a Table of Contents based on heading styles.

Example:

```text
1. Introduction ............ 1
2. Requirements ........... 2
3. Design .................. 4
4. Implementation .......... 6
5. Conclusion .............. 10
```

### Important concept

> Properly formatted headings make automatic Table of Contents generation easier.

---

# Format Painter

**Format Painter** copies formatting from one piece of content to another.

Example:

```text
Heading A
```

has:

```text
Bold
Blue
16pt
```

Format Painter can apply the same formatting to:

```text
Heading B
```

### Remember

> Format Painter copies **formatting**, not the actual text.

# Tables

Tables organize information into rows and columns.

Example:

| Name  | Department | Salary |
| ----- | ---------- | -----: |
| John  | IT         |  50000 |
| Priya | HR         |  45000 |
| Rahul | Sales      |  55000 |

You can:

* Insert rows
* Delete rows
* Insert columns
* Delete columns
* Merge cells
* Split cells
* Change borders
* Apply shading
* Align content

---

# Merge Cells

**Merge Cells** combines multiple selected cells into one cell.

Example:

Before:

```text
| A | B |
```

After merging:

```text
|    A + B    |
```

Useful for table headings.

---

# Split Cells

**Split Cells** divides one cell into multiple cells.

It is the opposite of merging cells.

# Mail Merge

**Mail Merge** is one of the most important Word concepts for assessment questions.

It is used to create multiple personalized documents from a common template and a data source.

### Example

Suppose you have:

| Name  | Email                                         |
| ----- | --------------------------------------------- |
| Rahul | [rahul@example.com](mailto:rahul@example.com) |
| Priya | [priya@example.com](mailto:priya@example.com) |
| Amit  | [amit@example.com](mailto:amit@example.com)   |

You create one letter:

```text
Dear «Name»,

Welcome to our organization.
```

Mail Merge produces personalized copies:

```text
Dear Rahul,

Welcome to our organization.
```

```text
Dear Priya,

Welcome to our organization.
```

```text
Dear Amit,

Welcome to our organization.
```

---

# Mail Merge Components

There are usually three important concepts:

### 1. Main Document

The template containing common content.

### 2. Data Source

Contains recipient information.

Example:

```text
Name
Address
Email
Employee ID
```

### 3. Merge Fields

Placeholders that are replaced with data.

Example:

```text
«Name»
«Address»
```

---

# Mail Merge Uses

Mail Merge can be used for:

* Letters
* Labels
* Envelopes
* Personalized emails
* Certificates
* Invitations

### Easy memory

> **Mail Merge = One template + many personalized outputs**

# Track Changes

**Track Changes** records modifications made to a document.

It can show:

* Insertions
* Deletions
* Formatting changes

Useful when:

* Reviewing documents
* Collaborating
* Editing reports
* Getting feedback

---

# Accept and Reject Changes

After Track Changes has recorded edits, a reviewer can:

```text
Accept
Reject
```

each change.

### Important distinction

```text
Track Changes → records edits
Comments      → adds feedback/notes
```

---

# Comments

Comments allow users to leave notes or feedback without changing the main document content.

Example:

```text
[Comment]
"Please verify this statistic."
```

Useful for collaboration and review.

---

# Track Changes vs Comments

| Track Changes              | Comments                    |
| -------------------------- | --------------------------- |
| Records document edits     | Adds feedback               |
| Shows insertions/deletions | Contains reviewer notes     |
| Can accept/reject changes  | Can resolve/delete comments |

---

# Images and Text Wrapping

Word allows images to be inserted into documents.

Text wrapping controls how text flows around an image.

Common options include:

* In Line with Text
* Square
* Tight
* Through
* Top and Bottom
* Behind Text
* In Front of Text

---

## In Line with Text

The image behaves like a character in the paragraph.

---

## Square

Text wraps around the rectangular boundary of the image.

---

## Behind Text

The image is positioned behind the text.

---

## In Front of Text

The image appears in front of the text.

### Important concept

> **Text wrapping controls the relationship between text and an inserted object.**

# Commonly Confused Concepts

## Header vs Footer

```text
Header → Top of page
Footer → Bottom of page
```

---

## Track Changes vs Comments

```text
Track Changes → Records edits
Comments      → Adds feedback
```

---

## Mail Merge vs Copy/Paste

```text
Mail Merge → Automatically creates personalized documents
Copy/Paste  → Manually duplicates content
```

---

## Styles vs Format Painter

```text
Styles        → Reusable predefined formatting
Format Painter → Copies formatting from one location to another
```

---

## Page Break vs Enter Key

```text
Ctrl + Enter → Proper page break
Enter        → Adds paragraph/line breaks
```

For structured documents, use a **page break** rather than pressing Enter repeatedly.

---

## Portrait vs Landscape

```text
Portrait  → Vertical
Landscape → Horizontal
```

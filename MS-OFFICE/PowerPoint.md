# PowerPoint Basics

## What is Microsoft PowerPoint?

**Microsoft PowerPoint** is presentation software used to create and deliver presentations.

Common uses include:

* Business presentations
* Project presentations
* Training material
* Academic presentations
* Client presentations
* Reports and data visualization

A PowerPoint presentation consists of multiple **slides**.

---

# Slides and Layouts

## Slide

A **slide** is an individual page/screen in a PowerPoint presentation.

A presentation may contain:

```text
Slide 1 → Title
Slide 2 → Introduction
Slide 3 → Project Details
Slide 4 → Results
Slide 5 → Conclusion
```

---

## Slide Layout

A **slide layout** defines the arrangement of placeholders on a slide.

Common layouts include:

* Title Slide
* Title and Content
* Section Header
* Two Content
* Comparison
* Title Only
* Blank

### Important distinction

**Layout** controls the structure/position of placeholders.

**Theme** controls the overall visual appearance.

# Grouping Objects

If multiple objects should move together, you can group them.

Shortcut:

```text
Ctrl + G
```

To ungroup:

```text
Ctrl + Shift + G
```

### Example

Suppose a slide contains:

```text
Image
+
Text
+
Arrow
```

You can group them so they behave as one object.

# Transitions

A **transition** is the visual effect that occurs when moving **from one slide to another**.

Examples:

* Fade
* Push
* Wipe
* Morph
* Split

### Important concept

> **Transition = between slides**

Example:

```text
Slide 1
   ↓
  Fade
   ↓
Slide 2
```

---

# Animations

An **animation** is an effect applied to an **object on a slide**.

Objects can include:

* Text
* Images
* Shapes
* Charts

Examples:

* Appear
* Fade
* Fly In
* Zoom

### Important concept

> **Animation = object on a slide**

Example:

```text
Slide 1
 ├── Text → Fade
 ├── Image → Zoom
 └── Shape → Fly In
```

---

# Transition vs Animation

This is a common MCQ topic.

| Transition                                | Animation                            |
| ----------------------------------------- | ------------------------------------ |
| Applied between slides                    | Applied to objects                   |
| Controls how one slide changes to another | Controls how an object appears/moves |
| Example: Fade between slides              | Example: Text Fly In                 |
| Slide-level effect                        | Object-level effect                  |

### Easy way to remember

```text
Transition → Slide
Animation  → Object
```

---

# Animation Types

PowerPoint animations are commonly grouped into four categories.

## 1. Entrance

Controls how an object enters.

Examples:

```text
Appear
Fade
Fly In
Zoom
```

---

## 2. Emphasis

Draws attention to an existing object.

Examples:

```text
Spin
Grow/Shrink
Pulse
```

---

## 3. Exit

Controls how an object leaves.

Examples:

```text
Disappear
Fade
Fly Out
```

---

## 4. Motion Paths

Moves an object along a specified path.

Examples:

```text
Lines
Arcs
Turns
Custom paths
```

---

# Animation Timing

Animations can be configured using:

### Start

**On Click**

Starts when you click.

### With Previous

Starts at the same time as the previous animation.

### After Previous

Starts automatically after the previous animation finishes.

# Slide Master

## What is Slide Master?

**Slide Master** controls the overall design and formatting of slides.

It can be used to maintain consistency across a presentation.

For example, you can set:

* Font
* Logo
* Background
* Colors
* Footer
* Placeholder positions

### Why is it useful?

Instead of manually changing every slide, you can make a change in the Slide Master and apply it across slides using that master/layout.

### Remember

> **Slide Master = consistent presentation-wide formatting**

# Themes and Design

## Theme

A **theme** provides a consistent visual style for the presentation.

A theme can include:

* Colors
* Fonts
* Effects
* Background styles

Example:

```text
Theme
 ├── Colors
 ├── Fonts
 └── Effects
```

---

## Difference Between Theme and Layout

| Theme                  | Layout                  |
| ---------------------- | ----------------------- |
| Controls visual design | Controls arrangement    |
| Colors                 | Placeholder positions   |
| Fonts                  | Title/content structure |
| Effects                | Slide structure         |

# Important PowerPoint Concepts

## Presentation

The complete PowerPoint file containing slides.

## Slide

An individual page/screen of a presentation.

## Layout

Controls the arrangement of placeholders on a slide.

## Theme

Controls the overall visual style.

## Transition

Effect between slides.

## Animation

Effect applied to objects on a slide.

## Slide Master

Controls consistent formatting and design across slides.

## Placeholder

A predefined area for content such as:

* Title
* Text
* Picture
* Chart
* Table

## Speaker Notes

Additional information for the presenter.

# Commonly Confused Concepts

## Transition vs Animation

```text
Transition → Between slides
Animation  → Objects on slides
```

---

## Slide Master vs Theme

```text
Slide Master → Controls layouts and consistent slide elements
Theme        → Controls visual style
```

---

## Normal View vs Slide Sorter

```text
Normal View  → Create/edit slides
Slide Sorter → Arrange/review slides
```

---

## F5 vs Shift + F5

```text
F5          → Start from beginning
Shift + F5  → Start from current slide
```

---

## `.pptx` vs `.ppsx`

```text
.pptx → Normal presentation file
.ppsx → Opens as a slideshow
```
